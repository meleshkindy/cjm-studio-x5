# CJM Studio — Sites

Публичная веб-версия CJM Studio с общей постоянной базой. Любой посетитель может создавать, изменять и удалять карты, справочники и комментарии без учётной записи. Автор новых изменений отображается как «Общий редактор». Управление пользователями не применяется.

React-интерфейс перенесён из локальной версии, включая карту, структуру, инициативы, редакции, отчёт с поиском и фильтрами и экспорт Excel. Все столбцы отчёта включены по умолчанию, технические ID не показываются.

## Хранение и перенос

- Worker API сохраняет записи в Sites D1 (`DB`), загруженные изображения — в R2 (`FILES`).
- `worker/seed.js` в Git содержит пустую базу. Рабочие данные импортируются отдельно через резервную копию; не коммитьте их в Git. Он применяется только при первом создании базы, последующие публикации не перезаписывают изменения посетителей.
- Локальная установка Go/PostgreSQL остаётся самостоятельной; автоматической синхронизации с ней нет.
- Сохранение проверяет версию карты и атомарную версию всей транзакции. Устаревшая запись получает HTTP 409. Изменения общих инициатив также меняют версии карт той же компании.
- Именованные редакции и восстановление сохраняются. Перед удалением карты сохраняется её снимок в резервных данных; он доступен в JSON-копии. Перед восстановлением базы текущие записи сохраняются в R2.
- Резервная копия веб-версии — JSON с картами, справочниками, комментариями, редакциями и изображениями. Это отдельный формат; SQLite-копии локальной установки импортируются скриптом переноса, а не через веб-форму.
- Ограничения: запись карты или редакции до 1,9 МБ, изображение до 10 МБ, файл восстановления до 25 МБ. Поиск и экспорт работают по всем строкам.

## Разработка

Node.js 24+, `npm install` в корне (workspace `web`), затем `npm run build`, `npm test`, `npm --prefix web run test:report`. Для локальной проверки `npm run dev` запускает Wrangler с локальными D1/R2. Настройки привязок — `wrangler.jsonc`.

Скрипт `node import-local.mjs` читает запущенную локальную установку на порту 8080, сохраняет SQLite-копию в игнорируемом каталоге `artifacts` и подготавливает начальные данные. Не запускать для обновления живой базы: seed не заменяет сохранённые данные Sites.

Сборка создаёт `dist/client`, `dist/server/index.js`, `dist/server/wrangler.json` и `dist/.openai/hosting.json`. Архив для Sites включает `.openai/hosting.json` и каталог `dist` из корня проекта после коммита и отправки точной версии исходников в репозиторий Sites. Идентификатор проекта хранится в `.openai/hosting.json`; повторно создавать проект нельзя.
