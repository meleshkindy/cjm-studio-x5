# CJM Studio одним HTML

После сборки готовый файл: `output/CJM-Studio.html`. В него встроены приложение, стили, экспорт Excel и выбранный снимок данных. Для работы приложения интернет не требуется; внешние ссылки в содержимом карт открывают соответствующие сайты.

Откройте скачанный HTML в обычном окне Chrome или Edge. Правки хранятся в IndexedDB этого браузера. Исходный файл на диске автоматически не изменяется. Для передачи сохранённых правок откройте «Резервные копии» → «Скачать HTML». Новый файл содержит свежую базу и получает отдельный идентификатор локального хранилища. Можно также выгрузить или загрузить JSON-копию.

У каждого коллеги своя база. Автоматической синхронизации с онлайн-версией или файлами других людей нет. Перед очисткой данных браузера сохраните новый HTML или JSON.

## Сборка и проверки

Node.js 24. Установите зависимости: `npm ci` в `portable`, затем `pnpm --dir web install --frozen-lockfile`. `npm run build` собирает IIFE с встроенным ExcelJS и CSS. Без рабочей копии сборка использует пустую базу `current-data.example.json`. Для включения своих данных сохраните JSON-копию веб-версии как `current-data.json` или передайте путь: `node build.mjs путь/к/копии.json`. Рабочие данные и готовый HTML исключены из Git. Обновление этого файла и повторная сборка не меняют опубликованный сайт.

`node test-portable.mjs` проверяет в JSDOM с fake-indexeddb запуск всего готового HTML, сохранение и повторное открытие, конфликт устаревшей записи, формирование Excel на отдельной тестовой карте, отсутствие технических ID, изображения, повторный экспорт рабочего HTML с новыми данными и восстановление JSON. Проверка запрещает внешние fetch-запросы: их количество должно оставаться нулевым.

Прямой запуск через `file://` не проверен автоматизированным браузером: его политика разрешает только HTTP/HTTPS. Эта проверка не заменяется заявлением о проверке двойного щелчка. Ограничения корпоративного браузера на локальное хранилище могут потребовать открытия файла в другом разрешённом браузере.
